# 拼多多商家申诉工具 — 使用手册

面向对象：日常使用这个工具处理店铺申诉的运营人员，不需要懂代码。

---

## 1. 这是什么工具

这个工具能自动帮你做完"处理一条客诉申诉"的整套流程：

1. 打开店铺后台，找出当前可以申诉的订单；
2. 查看这条订单买家和客服的聊天记录，判断该用哪种理由申诉；
3. 自动生成一段申诉说明文案；
4. 打开申诉表单，自动选好理由、填好说明、上传凭证；
5. 提交。

你要做的事情很少：**登录一次店铺、勾选要处理的店铺、点启动**，剩下的它自己跑。跑的过程中浏览器窗口会真的打开、真的操作，这是为了让拼多多后台看起来跟真人操作一样，不是后台静默运行——**不要关掉或手动操作正在处理的浏览器窗口**，会打断它。

---

## 2. 开始之前你需要知道

⚠️ **验证码不会被强行绕过。** 软件会先尝试自动识别常见的两类验证码（旋转拼图、字符验证码），识别不了或者连续 3 次识别失败，会自动跳过这一单继续处理下一单——**不会一直卡着等你**。如果发现某个店铺经常因为验证码失败被跳过，属于正常现象，不需要一直守着浏览器手动过验证码。

⚠️ **关闭软件窗口前，看一眼有没有任务在跑。** 如果 C 页正在跑批量处理，直接点窗口右上角的 X 关闭，软件会先弹提示问你要不要先"优雅停止"（最长等 30 秒，等当前正在处理的这一单做完）。**建议养成先点"优雅停止"、看到状态变回空闲再关软件的习惯**，比较省心。

---

## 3. 启动软件

按开发人员提供的方式启动（通常是双击一个启动脚本，或者运行一条命令）。打开后是一个左侧四个入口的窗口：**总览仪表盘 / 店铺管理 / 运行控制 / 报表/导出**。

---

## 4. 店铺管理（B 页）——先在这里把店铺加进来

| 你能做的事 | 怎么做 |
|---|---|
| **新增一家店铺** | 点"新增店铺"，输入一个便于识别的名字（比如店铺简称），点开始登录 → 会弹出一个真实浏览器窗口 → **在这个窗口里正常登录你的拼多多商家后台账号**（扫码/账号密码都行）→ 登录成功后软件会自动感知到，不需要手动点确认，也不需要回到软件这边操作，等提示"登录成功"就行 |
| **重新登录**（登录状态失效了） | 在店铺列表里右键这家店铺 → 选"重新登录" → 跟新增流程一样，弹浏览器窗口重新登录一次 |
| **停用/启用** | 暂时不想让某家店参与批量处理时右键"停用"，需要恢复时右键"启用"——停用不会删除任何数据，随时能恢复 |
| **重置今日状态** | 某家店今天已经模拟提交跑完一轮、被标记"今日已完成"，你想当天再切到真实提交重新跑一遍——右键"重置今日状态"，它会变回"尚未开始"，下一轮会重新处理 |
| **删除** | 右键"删除"——只删除这家店铺保存的登录状态，历史订单处理记录不会丢 |

**"登录状态"这一列显示什么**：

- **已登录**（绿色）：这家店铺当前有有效的登录状态；
- **未登录**（红色）：从来没登录过，或者最近一次实际运行时检测到登录已经失效——两种情况处理方式一样，都是重新登录一次。

## 5. 运行控制（C 页）——这里是实际跑批处理的地方

「售后申诉」标签页用于安全验证售后维权流程：设置每家店铺最多处理数量后，
程序会保存退款申请单、查询并分析聊天、上传必填和选填凭证、填写最高可申诉
金额和申诉描述，最后自动点击“取消”。当前版本不会点击“提交申诉”。
列表中的订单信息、发货状态、实收/退款金额、退款时间、申诉项和倒计时都会
独立保存。货款申诉会按页面实际选项在“质量问题但凭证不足”和“非以上申诉
原因”之间选择；运费申诉固定选择“退货运费 / 消费者无理由退货，退货运费
不应商家承担”。未知申诉项不会自动猜测，而是记录失败并保存现场截图。

### 5.1 手动跑一轮

1. 勾选这次要处理的店铺（提供"全选"/"全不选"按钮，被停用或未登录的店铺不会出现在列表里）；
2. 设置"并发上限"——同一时刻最多同时开几家店铺的浏览器窗口。根据电脑配置和网络情况调整，一般 3~5 就够用；
3. 界面上有一个实时状态小表格，能看到每家店铺当前处理到第几单、还剩多少单；下面的日志区能看到详细的处理过程文字记录；
4. 想中途停下来，点"优雅停止"——**不会打断正在处理中的这一单**，做完这一单之后不再开始新的，然后所有浏览器都关掉。

**跑完这一批之后软件不会自动继续跑下一批**——勾选的店铺处理完一轮就停下来，需要下次手动或定时再启动。

### 5.2 什么时候一批店铺没法一天跑完

如果店铺数量比较多、一天之内不一定能全部跑完，这是正常的，原因有几种（不需要记住细节，出问题找开发人员时可以描述现象）：

- 勾选的店铺数超过了并发数，排不上号的店铺会等下一轮/下一天，**软件会自动记住"谁被冷落得最久"，下次优先给它安排名额，不会一直只处理同一批店铺**；
- 到了截止时间（比如定时任务设置的结束时间），正在处理的订单会做完，但还没轮到的店铺会等明天继续。

**总之：没处理完的不会丢，第二天会继续处理，不需要你手动干预。**

### 5.3 关于"排队中"状态

如果某家店铺的"今日调度状态"显示"排队中，等待优先补位"，意思是这一轮并发名额不够、还没轮到它开工，**不是这家店出了问题**。它会被优先安排到下一轮，不需要处理。

### 5.4 每日定时自动运行（可选）

如果不想每天都手动点启动/停止，可以打开"启用每日自动运行"，设置开始和结束时间（默认早上 8 点到晚上 8 点）。

- **第一次打开这个开关时会弹一次确认框**，讲清楚"以后每天这个时间段会自动真实提交，不会再逐次确认"——确认之后，往后每天到点自动开始、到点自动优雅停止，都不会再弹窗打扰你；
- **前提：软件窗口必须一直开着**，这不是电脑关机也能运行的后台任务，是软件自己内置的一个计时器，软件没开着就不会触发；
- 到了结束时间，如果任务还在跑，会自动"优雅停止"（不打断正在处理的订单）；没处理完的订单，第二天会自然继续处理。

### 5.5 遇到"检测到已经有另一个调度进程在运行"

说明同一批店铺已经有别的地方在跑了（可能是你自己之前开的另一个窗口，也可能是技术人员在用命令行跑）。**不要在两个地方同时对同一批店铺跑批处理**，会互相冲突。确认清楚是不是自己重复开了，关掉一个再继续。

### 5.6 查询申诉结果

申诉提交之后，拼多多平台一般要 1-2 个工作日才会给出审核结果（通过/驳回）。**"查询申诉结果"这个按钮就是把这个结果同步回软件**，跟上面"启动"批量处理是两件独立的事——不需要每次提交完马上点，过 1-2 天再点效果最好。

1. 跟"启动"一样，先勾选要查询的店铺；
2. 点"查询申诉结果"——软件会依次打开每家店铺的浏览器，进这家店的客诉申诉页查最近几天提交的记录，查完自动关掉，换下一家；
3. 日志区能看到每家店铺查到了几条、匹配上了几条；
4. 全部店铺查完会弹一个汇总提示，查到的结果同时会更新到"报表/导出"（F 页）里对应订单的状态上，不需要手动刷新。

**几点说明**：

- 默认查最近 3 天提交的记录，够覆盖"1-2 个工作日出结果"这个窗口；
- 跟"启动"互斥——两边都要开浏览器操作同一批店铺的账号，不能同时跑；任何一边正在跑的时候点另一边，会提示先等它结束再试；
- 这是只读查询，不会提交或修改任何申诉，可以放心多点几次，不会有副作用；
- 某个订单查了好几次结果都没变化（比如一直显示对应状态没更新），大概率是拼多多那边还没审完，过几天再查一次就好。

## 6. 总览仪表盘（A 页）——一眼看整体情况

顶部几个数字：店铺总数、今日已完成、待处理订单、今日已提交、今日失败。

下面是每家店铺一张卡片，展示：登录状态、今日调度状态、待处理/已提交/已跳过/失败数量、最近一次有动静的时间。想快速了解"现在整体情况怎么样"来这里看就够了。

## 7. 报表/导出（F 页）——查历史数据、导出给别人看

1. 选店铺（或"全部"）、选时间范围（全部/今天/近 7 天/近 30 天），点"刷新"；
2. 上方是图表，下方是明细表格，包含每个订单的完整处理信息（问题类型、状态、申诉凭证分类、提交时间等）；
3. 需要发给别人或者存档时，点"导出 Excel"或"导出 CSV"；
4. 明细表格里点某一行，能预览这条订单的凭证截图（填表后截图/出错时的现场截图），方便核对处理是否正确。

## 8. 常见问题

**Q：勾选的店铺跑到一半，我把软件窗口关了，会怎么样？**
A：软件会先拦一下，问你要不要先优雅停止。如果你选择"仍然关闭"，它会先尝试等当前处理中的订单做完再关（最长等 30 秒）。没处理完的店铺，下次打开软件重新跑这批店铺时会自动继续，不会漏掉、也不会重复处理已经交过的订单。

**Q：某家店铺一直显示"排队中"怎么办？**
A：不用管，说明这一轮并发名额不够、还没轮到它，软件会记住并在后续优先安排给它名额。如果连续好几天都是这个状态，可以考虑把"并发上限"调大一点，或者减少同时勾选的店铺数量。

**Q：验证码总是失败被跳过怎么办？**
A：正常现象，自动识别不是 100% 成功率。被跳过的订单不会永久消失，下一轮采集时如果它还处于可申诉状态，会重新出现在待处理列表里，有机会再次尝试。

**Q：某家店铺"登录状态"显示未登录，但我记得之前登录过？**
A：登录状态可能会过期失效，右键这家店铺选"重新登录"，重新走一次登录流程即可，不影响这家店铺已有的历史处理记录。

**Q：为什么有的店铺几秒钟就处理完了，看起来什么都没做？**
A：如果这家店铺当前没有新的可申诉订单，软件打开浏览器确认一下就会立刻关掉、标记"今日已完成"，不是故障。

**Q：能不能同时用两个窗口/让技术人员同时用命令行跑同一批店铺？**
A：不可以，会互相冲突。软件本身有防重复运行的保护，重复启动会提示"检测到已经有另一个调度进程在运行"并且不会真正开始。

**Q：申诉提交之后多久去点"查询申诉结果"比较合适？**
A：拼多多一般 1-2 个工作日才出结果，提交当天查大概率还是"审核中"，白跑一趟。建议提交后隔 1-2 天再查，或者固定每天开工前查一次前几天提交的。

## 9. 需要联系技术支持的情况

- 软件启动报错、打不开；
- 某家店铺连续多天都无法登录成功；
- 报表数据明显不对（比如导出的 Excel 打不开、数字对不上）；
- 出现本手册没提到的报错提示。

反馈时如果能截图或者描述清楚当时点了什么按钮、看到了什么提示，会更快定位问题。
